# TCPDF 7 runtime font subset

Generated from tecnickcom/tc-lib-pdf-font 4.3.3 using its upstream util/bulk_convert.php utility and the exact dependency graph recorded in this repository composer.lock.

SScribe intentionally retains only the standard PDF core font descriptors and DejaVu Sans regular, bold, italic, and bold-italic data required by the PDF exporter.

The release build copies this deterministic subset into the prefixed tc-lib font package. Do not edit generated .json, .z, or .ctg.z files manually.
