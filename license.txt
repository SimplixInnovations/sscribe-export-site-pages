TCPDF Runtime Font Data
=======================

SScribe stages only the TCPDF 7 runtime font subset required for rendering:
the standard PDF Core14 descriptors used by TCPDF fallbacks and DejaVu Sans
regular, bold, italic, and bold-italic data used by SScribe.

* DejaVu Sans font data retains the upstream DejaVu license at
  vendor-prefixed/tecnickcom/tc-lib-pdf-font/target/fonts/dejavu/LICENSE.
* Core14 metric data retains the Adobe redistribution notice at
  vendor-prefixed/tecnickcom/tc-lib-pdf-font/target/fonts/core/LICENSE.

The tracked build inputs and their provenance live in
scripts/resources/tcpdf-fonts/ and docs/BUILD_TRANSFORMATIONS.md. These build
inputs are not shipped as duplicate source files; their exact staged copies
are included in the runtime dependency tree.
