Third-Party Assets
==================

This plugin bundles the Amiri font family (assets/fonts/amiri/),
copyright 2010-2022 The Amiri Project Authors
(https://github.com/aliftype/amiri). The Amiri fonts are licensed
under the SIL Open Font License, Version 1.1. A copy of the OFL is
included in assets/fonts/amiri/OFL.txt. The OFL is compatible with
the GPL v2; the font may be redistributed with this plugin under the
terms of the OFL.

This plugin also bundles code from the following open-source libraries,
all of which are compatible with the GPL v2. The list below reflects
only what actually ships in the release archive; license texts for
each library are preserved alongside its source in vendor-prefixed/
so a reviewer can verify attribution without leaving the ZIP.

* PHPWord (LGPL-3.0-or-later) : DOCX export. Source:
  https://github.com/PHPOffice/PHPWord. LGPL is compatible with GPL
  v2 when dynamically linked; PHPWord is loaded at runtime through
  its own autoloader, satisfying the LGPL linking exception. Full
  license text: https://www.gnu.org/licenses/lgpl-3.0.html
* mPDF (GPL-2.0-or-later) : PDF export. Source:
  https://github.com/mpdf/mpdf. mPDF is licensed under the same GPL
  v2 (or later) terms as this plugin.
* FPDI (MIT) : PDF page composition primitives. Source:
  https://github.com/setasign/fpdi. The shipped copy has the
  FPDF-extending classes pruned because the upstream setasign/fpdf
  parent is not bundled; only the standalone parser, type system,
  and helpers remain. MIT is a permissive license compatible with
  GPL v2 redistribution.
* phpoffice/math (MIT) : arithmetic helpers used by PHPWord.
* myclabs/deep-copy (MIT) : deep-clone helper used by PHPWord for
  template and style-graph operations.
* paragonie/random_compat (MIT) : retained for legacy PHP-version
  detection (the polyfill itself is dead weight on PHP 8.2+; the
  package's detection code still drives a guard in this plugin).
* psr/container (MIT) : PSR-11 container interface used by the
  bundled dependency injection container.
* psr/http-message (MIT) : PSR-7 HTTP message interfaces used by
  the mPDF PSR HTTP shim.
* psr/log (MIT) : PSR-3 logger interface consumed by the mPDF
  PSR log-aware trait.
* mpdf/psr-http-message-shim (MIT) : bridges mPDF's internal HTTP
  client to PSR-7 messages.
* mpdf/psr-log-aware-trait (MIT) : bridges mPDF's logging to
  PSR-3 loggers.

Each library's full license text is preserved alongside its source
in the plugin's vendor-prefixed/ directory.
