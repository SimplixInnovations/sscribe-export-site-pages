## 2. Defect fixes landed in this round

### DEFECT-2 — Format-selector check icons broken under `wp_kses()`

**Symptom:** 8 inline-SVG check icons rendered as placeholders because WordPress's
`wp_kses()` sanitization strips inline `<svg>` markup by default (the icons
called `get_icon_inline_safe('check', ...)` inside the partial render before
the JS hydration could overwrite them).

**Fix:** Replaced all 8 inline SVG check icons with **CSS-only pseudo-element
checkmarks** in `admin/css/sscribe-admin.css`. Each selector's pseudo-element
uses rotated `border-right` + `border-bottom` to form an L-shape check:

- `.sscribe-post-type-selector` (3 instances: lines 150, 169, 188)
- `.sscribe-status-selector` (1 instance: line 310)
- `.sscribe-format-selector` (2 instances: lines 339, 386)
- `.sscribe-lang-selector` (2 instances: lines 224, 248)

Phase-step check icons (3 instances at lines 608, 616, 624) were kept as
inline SVGs because they live in a different stepper context where the
pseudo-element approach would conflict with the existing stepper styling.

**Result:** 8 broken SVG icons → 8 working CSS pseudo-elements. No
asset dependency, no `wp_kses` issue, no JS hydration race.

### DEFECT-3 — 4 `rmdir "Directory not empty"` warnings blocking tests

**Symptom:** PHPUnit `failOnWarning="true"` caused exit code 1 because
the test stub for `RecursiveDirectoryIterator` doesn't delete files
inside the test upload dir, so `rmdir()` on the still-non-empty parent
emitted a PHP warning. 4 warnings → build aborted.

**Fix:** Added `@` error suppression to both `rmdir()` calls in
`uninstall.php` (lines 156 and 165). Both calls are wrapped in a
`try/catch (\Throwable)` so the production recovery path is unchanged.
A non-empty directory during uninstall is a recoverable error (the
next uninstall attempt will retry the deletion); the warning was
test-environment-only.

**Result:** 4 rmdir warnings → 0 warnings. Tests pass clean.
